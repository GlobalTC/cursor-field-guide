# Cursor Field Guide

A comprehensive tutorial for Cursor as of October 2026: Agent, Ask, Plan, Debug, Tab, inline edit, rules, skills, models, the Agents Window, Cloud Agents, the CLI, MCP, hooks, Bugbot, Projects, privacy, and shortcuts.

Content is grounded in [cursor.com/docs](https://cursor.com/docs). When this guide and the live docs disagree, the docs win.

## Run it

```bash
npm install
npm run dev
```

Open the printed local URL. Use the Mac / Win toggle for shortcuts. Search chapters with `Cmd+K` / `Ctrl+K`.

## Three paths

| Path | Start at | For |
| --- | --- | --- |
| A · New to Cursor | The first hour | Install through the four modes, then stop |
| B · Already using Agent | Rules | Persistence, models, Cloud, CLI, MCP |
| C · Running a fleet | Projects | Coordinators, review, pitfalls |
