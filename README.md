# Cursor Field Guide

A comprehensive, locally runnable tutorial for Cursor as of October 2026. It covers the Agent panel, Ask / Plan / Debug, Tab, inline edit, rules, skills, models, the Agents Window, Cloud Agents, the CLI, MCP, hooks, Bugbot, Projects, privacy, and shortcuts.

Content is grounded in [cursor.com/docs](https://cursor.com/docs). When this guide and the live docs disagree, the docs win.

## Run it

```bash
npm install
npm run dev
```

Then open the printed local URL. Use the Mac / Win toggle for shortcuts. `Cmd+K` / `Ctrl+K` searches chapters.
